# 오늘 뭐하지? | 랜덤 룰렛

점심 메뉴, 벌칙, 모임 활동 등 여러 선택지 중 하나를 재미있게 결정할 수 있는 웹 기반 룰렛 앱입니다. 선택지를 입력하고 가중치와 색상을 설정한 뒤 Canvas 룰렛을 돌려 무작위 결과를 확인할 수 있습니다.

## 바로가기

- **GitHub 저장소**: [yooyunwoo/vibe-midterm-202502080](https://github.com/yooyunwoo/vibe-midterm-202502080)
- **GitHub Pages 배포**: [오늘 뭐하지? | 랜덤 룰렛](https://yooyunwoo.github.io/vibe-midterm-202502080/)

> GitHub Pages는 저장소의 `main` 브랜치에 반영된 최신 커밋을 기준으로 배포됩니다. 배포 직후에는 반영까지 잠시 시간이 걸릴 수 있습니다.

## 주요 기능

- Canvas 2D 기반 원판 룰렛 회전 애니메이션
- 최소 2개부터 최대 50개까지 선택지 입력
- 선택지 행 추가·삭제 및 번호 자동 정렬
- 선택지별 가중치 설정 및 당첨 확률 표시
- 가중치에 따른 원판 섹터 크기와 실제 결과 확률 반영
- 선택지별 색상 선택
- 결과 섹터의 흰색 테두리 및 브라운 글로우 펄스 효과
- 결과 확인 후 다시 돌리기
- 프리셋 저장·불러오기·삭제
- 선택지와 프리셋의 `localStorage` 저장
- 반응형 레이아웃 및 모바일 화면 지원
- `prefers-reduced-motion` 사용자 설정 지원
- 키보드 조작 및 `aria` 기반 접근성 지원
- `OkDandan` 웹폰트 적용

## 사용법

### 1. 선택지 입력

1. 화면의 선택지 행에 메뉴, 벌칙, 활동 등의 내용을 입력합니다.
2. 기본으로 제공되는 두 행을 사용하거나 **선택지 추가** 버튼으로 행을 추가합니다.
3. 선택지를 삭제할 때는 각 행의 `×` 버튼을 사용합니다.
4. 선택지는 최소 2개를 입력해야 룰렛을 실행할 수 있습니다.

### 2. 가중치와 색상 설정

- **가중치**: 숫자가 클수록 해당 선택지가 선택될 확률이 높아집니다.
- **확률 표시**: 각 행의 확률은 전체 가중치 합계에 따라 자동 계산됩니다.
- **색상 선택**: 각 행의 색상 버튼을 눌러 원판 섹터 색상을 바꿀 수 있습니다.

기본 가중치는 1이며, 모든 선택지의 가중치가 같으면 동일한 확률로 선택됩니다.

### 3. 룰렛 실행

1. 최소 2개의 선택지를 입력합니다.
2. **룰렛 돌리기** 버튼을 누릅니다.
3. 룰렛이 회전한 뒤 선택된 결과가 결과 카드에 표시됩니다.
4. 결과 섹터는 흰색 테두리와 은은한 브라운 글로우로 강조됩니다.
5. 다시 선택하려면 **다시 돌리기** 버튼을 누릅니다.

### 4. 프리셋 사용

1. 선택지를 입력한 뒤 **이 목록 저장하기**를 누릅니다.
2. 프리셋 이름을 입력하고 저장합니다.
3. 상단의 **프리셋** 버튼에서 저장된 목록을 확인합니다.
4. **불러오기**로 선택지, 가중치, 색상을 복원합니다.
5. 더 이상 필요하지 않은 프리셋은 **삭제**할 수 있습니다.

## 데이터 저장

선택지와 프리셋은 별도의 서버로 전송되지 않고 현재 브라우저의 `localStorage`에 저장됩니다.

- 브라우저 또는 사이트 데이터를 삭제하면 저장된 데이터도 삭제될 수 있습니다.
- 다른 브라우저나 다른 기기에서는 저장 데이터가 자동으로 공유되지 않습니다.
- 기존 문자열 형태로 저장된 선택지는 새 선택지 구조로 자동 변환됩니다.

## 로컬 실행

별도의 빌드 과정이나 의존성 설치가 필요하지 않습니다.

1. 저장소를 클론합니다.

   ```bash
   git clone https://github.com/yooyunwoo/vibe-midterm-202502080.git
   cd vibe-midterm-202502080
   ```

2. `index.html`을 브라우저에서 엽니다.

또는 VS Code에서 프로젝트 폴더를 연 뒤 `index.html`을 브라우저로 실행하면 됩니다.

## 자동 Git 동기화

VS Code에서 프로젝트 폴더를 열면 `.vscode/tasks.json`의 `Auto Git Sync` 작업을 실행할 수 있습니다.

- 파일 변경이 일정 시간 멈추면 변경 사항을 자동 스테이징합니다.
- 자동 커밋을 생성합니다.
- 현재 브랜치의 `origin` 원격 저장소로 푸시합니다.

자동 푸시를 사용하려면 GitHub 인증과 원격 저장소 권한이 미리 설정되어 있어야 합니다.
