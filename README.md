# ☕ 카페 온기 — 메뉴 주문 웹앱

카페 메뉴를 골라 장바구니에 담아 주문하고, 관리자가 주문 현황과 재고를 한 화면에서 확인·처리하는 웹앱입니다. 서버나 프레임워크 없이 **HTML, CSS, JavaScript만**으로 만들었고, 데이터는 브라우저 `localStorage`에 저장합니다.

## 주요 기능

### 고객
- **메뉴 탐색**: 커피 / 논커피 / 디저트 카테고리별 메뉴 카드
- **옵션 선택**: 음료는 샷 추가(+500원), 시럽 추가(+0원)를 고르고 수량 선택 (디저트는 수량만)
- **장바구니**: 수량 조절, 삭제, 비우기, 합계 자동 계산, 새로고침해도 유지
- **주문하기**: 주문자 이름(또는 테이블 번호)과 요청사항 입력 → 주문번호 발급
- **주문 조회**: 주문번호로 현재 상태(접수 / 준비중 / 완료 / 취소) 확인
- **재고 안내**: 메뉴 이름 옆에 깜빡이는 배지 — `품절`, `품절 임박`(1개 남음), `🔥 인기`(판매 상위 3개)

### 관리자 (로그인 없음)
- **주문 현황**: 오늘 주문 수, 상태별 건수, 오늘 매출, 주문 카드 목록(최신순)
- **제조 처리**: `제조 시작` → `제조 완료`로 상태 변경, 주문 취소
- **주문 관리**: 상태 필터, 주문번호·이름 검색, 주문 한 건씩 삭제 / 전체 삭제
- **재고 관리**: 메뉴별 재고 현황 확인·수정, 재고 부족·품절 배지, 품절 처리/판매 재개
- **인기 메뉴**: 판매 수량 상위 메뉴 집계

### 재고 규칙
- 주문하면 수량만큼 재고가 줄고, 0이 되면 자동으로 품절됩니다.
- 재고보다 많이 담거나 주문할 수 없습니다 (장바구니에 담긴 수량 포함).
- 주문을 **취소**하면 재고가 복구됩니다. 주문을 **삭제**하면 기록만 지워지고 재고는 복구되지 않습니다.

## 사용법

### 실행
- **배포 페이지**: 위 링크를 열면 바로 사용할 수 있습니다.
- **로컬 실행**: 저장소를 받아 `index.html`을 브라우저로 열면 됩니다. 빌드나 서버가 필요 없습니다.

```bash
git clone https://github.com/yooyunwoo/vibe-midterm-202502080.git
cd vibe-midterm-202502080
# index.html을 브라우저로 열기
```

### 주문하기 (고객)
1. 상단 탭이 **주문하기**인 상태에서 카테고리를 고르고 메뉴의 `담기`를 누릅니다.
2. 옵션(샷/시럽)과 수량을 정하고 `담기`를 누릅니다.
3. 오른쪽 위 🛒 버튼으로 장바구니를 열어 수량을 확인합니다.
4. 주문자 이름(또는 테이블 번호)을 입력하고 `주문하기`를 누릅니다.
5. 발급된 주문번호를 기억해 두고, 화면 아래 **내 주문 조회**에 입력하면 진행 상태를 볼 수 있습니다.

### 주문 처리 (관리자)
1. 상단의 **관리자** 탭을 누르면 바로 대시보드가 열립니다.
2. 새 주문 카드에서 `제조 시작` → `제조 완료`를 눌러 상태를 바꿉니다. 필요하면 `취소`를 누릅니다.
3. 오른쪽 **재고·품절 관리**에서 메뉴별 재고 수를 고치거나 품절 처리·판매 재개를 합니다.
4. 필요 없는 주문은 카드의 `삭제`, 모든 주문은 `전체 삭제`로 지웁니다 (확인 창이 뜹니다).

> 고객 화면과 관리자 화면은 같은 페이지의 탭이고 같은 브라우저 저장소를 씁니다. 그래서 주문한 직후 관리자 탭으로 바꾸면 해당 주문이 바로 보입니다.

## 알아둘 점

- 데이터는 **사용 중인 브라우저의 `localStorage`에만** 저장됩니다. 다른 기기·다른 브라우저와 주문이 공유되지 않고, 브라우저 데이터를 지우면 주문 기록도 사라집니다. (시연·학습용)
- 관리자 화면에는 로그인이 없어서 누구나 열 수 있습니다.
- 웹폰트(JoseonGulim)는 CDN에서 불러옵니다. 오프라인이면 시스템 폰트로 보입니다.
- 처음 접속하면 기본 메뉴 9종(음료 5, 디저트 4)과 재고가 자동으로 채워집니다.

## 기술 스택

- HTML5, CSS3(CSS 변수, 플랫 + 둥근 모서리 베이지 테마), JavaScript(ES2020, 모듈 번들러 없음)
- 저장소: `localStorage` (스키마 버전 관리·마이그레이션 포함)
- 프레임워크, 빌드 도구, npm 패키지 없음
